# StudyMate AI (Android)

Stage 1: onboarding (name, class or level, subjects) saved on the phone, and a debug APK built by GitHub Actions.
Stage 2 (next): on-device AI tutor through llama.cpp, then voice (whisper.cpp), then textbook import with page citations.

Build: open the **Build StudyMate AI APK** workflow in Actions and download the `StudyMate-AI-debug-apk` artifact.
Install on the phone by allowing installs from unknown sources.
